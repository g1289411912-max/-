导入条目（.md）

直接吃你笔记里的简表格式，每行一个动词、四列：
原型 — 过去式 — 过去分词 — 中文释义
例：fahren — fuhr — gefahren — 行驶，驾驶 · abfahren — fuhr ab — abgefahren — 出发，驶离
也认 an/bauen — baute an — angebaut — 种植，扩建（可分前缀带斜杠）。
多个变体用斜杠并列：anwenden — wandte an / wendete an — angewandt / angewendet — 应用； 若过去式与分词之间有破折号（verwenden — verwandte / verwendete — verwendet 这类写法），也会自动识别。
**标题**行、（补充）前缀都会自动忽略。

可一次性多选多个文件（Ctrl/Shift 多选），自动合并导入。

导入解析（.md）

格式与你的 表格解析.md 一致，每块用一个空行隔开：
原型：sein / 答案：war / gewesen / 类型：特殊完全不规则动词 / 意义：是，存在 / 例句1：… / 例句2：…
解析按 原型 自动关联到条目（an/bauen ↔ anbauen 也算同一个）。答完题后可展开「📖 解析」看类型、意义与例句。

可一次性多选多个文件，自动合并导入。

从哪个动词开始？
