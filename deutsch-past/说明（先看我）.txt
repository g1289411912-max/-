  德语过去助手 · 手机版（拖这个文件夹就能变成网址）
================================================================

【怎么用】三步，1 分钟

1. 这个文件夹的名字保持  deutsch-past  不要改
   （改了名网址就会跟着变；也别改成中文名，网址里会变成一串乱码）

2. 电脑浏览器打开你的仓库：
       https://github.com/g1289411912-max/-
   点  Add file  →  Upload files
   把【整个 deutsch-past 文件夹】拖进网页里（拖文件夹本身，别只拖里面的文件）

   ⚠️ 要拖到仓库的【根目录】，不要拖进已有的 jiebin 文件夹里面。
      正确结果是仓库首页出现一个 deutsch-past 文件夹，里面是 5 个文件。

3. 拉到底点  Commit changes ，等 30～60 秒

【你的网址】

    https://g1289411912-max.github.io/-/deutsch-past/

   手机浏览器打开它 → 直接就能练（已内置 128 个动词 + 全部解析，不用导入任何文件）

【加到手机主屏，当 App 用】
   iPhone Safari   ：底部分享 → 添加到主屏幕
   Android Chrome  ：右上角菜单 → 添加到主屏幕 / 安装应用
   加完点图标是全屏，而且【断网也能练】

【文件夹里是什么】
   index.html      应用本体（就是 德语过去助手.html）
   data.js         内置词表（128 个动词 + 类型 + 意义 + 例句）—— 千万别漏上传这个
   manifest.json   让它能"添加到主屏"
   sw.js           断网也能用（离线缓存）
   icon.svg        主屏图标
   README.md       说明（给手机上看不必要，留着也无妨）

   这 5 个文件缺一不可；只拖单个文件会散落到仓库根目录，网址就会 404。

【怎么练】
   看动词原型 → 自己写「过去式」和「过去分词」→ 回车判题
   不会就点「不会，看答案」：自动加进错题本 + 展开解析

【以后更新】
   · 只是笔记改了几个词：手机上点「导入条目(.md)」选新的 表格.md 即可，进度笔记都保留
   · 想更新"打开就有"的内置词表：电脑上改好 表格.md / 表格解析.md，
     跑一次  node tools\gen-data.js ，把新的 data.js 覆盖上传到仓库的 deutsch-past\data.js
   · 改完页面还是旧版？首页点「检查更新」，或在手机浏览器里清一下该站点缓存

【常见问题】
   Q 打开是 404？
     等 1 分钟再刷；确认文件在 deutsch-past/ 里面，而且入口文件名就是 index.html
   Q 打开后一个动词都没有？
     data.js 没上传成功。补救：点「导入条目(.md)」手动导入 表格.md
   Q 会占用你仓库的容量吗？
     不会，总共约 110 KB，而且仓库里只有代码，没有你的练习记录
   Q 练习记录会上传吗？
     不会，全部存在手机浏览器本地；换手机或清缓存才会丢
