错题本 · 三层瀑布复习

答错进 L1；L1 答对=毕业，答错→L2；L2 答对=毕业，答错→L3；L3 答对=毕业，答错留在 L3。每层都能单独开练。

按 1-4 选择 · 回车 = 下一条 · ← = 上一条

导入条目（.md）

每行一条，格式：- 动词 介词 + 格 (中文释义)
例：- abfallen von + D (背叛) · - an/fangen mit + D (以…开始) · - ein/setzen + A für + A (致力于)
可分动词用 / 标前缀；格标记 + D / + A / + Gen 可写可不写；### A 这类首字母标题、-/编号前缀都会自动忽略。
没有介词的条目（如 auf/wachsen (长大)、begegnen + D (遇见)【纯格】）会自动跳过，不计入练习。

可一次性多选多个文件（Ctrl/Shift 多选），自动合并导入。

导入解析（.md）

格式与 解析.md 一致：条目行 **abfallen von + D（背叛；脱离）**，下面跟 动词：…、助记：…、例句： + 1. …。
解析与条目按 动词 自动关联（an/fangen ↔ anfangen、带不带的 sich 都能对上）。答完题后可点「📖 解析」查看。

可一次性多选多个文件，自动合并导入。

从哪条开始？

点任意条目，将从它开始按词表顺序练到末尾。

选词练习

勾选想练的条目（也可搜索），点「开始练习所选」。所选条目会打乱顺序出题。

📝 笔记

写下你的纠正、助记。按「动词 + 介词」独立保存，换词表、重置进度都不丢失。
