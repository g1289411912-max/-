# 手机部署说明（GitHub Pages）

目标：**手机上打开一个网址就能用**，而且以后词表更新了，手机上重新导入一次新的 `.md` 就行。

> 你已经有仓库了（`g1289411912-max/-`），所以下面「二」只要把 `jiebin` 文件夹拖上去，一次搞定。

---

## 一、这个文件夹里有什么

| 文件 | 作用 |
|---|---|
| `index.html` | **应用本体**（就是 `德语介宾助手.html` 的副本，内容完全一致） |
| `manifest.json` | 让手机能把网页「添加到主屏」当 App 用（有图标、全屏、独立窗口） |
| `sw.js` | Service Worker：**断网也能打开**、断网也能练（数据是本地的） |
| `icon.svg` | 主屏图标 |

整个文件夹里**没有服务器、没有接口**：条目和解析都是你在手机上直接选文件导入，存在手机本地。

---

## 二、放上 GitHub（拖文件夹，一步搞定）

和上次放「德语背单词-网页版」完全一样的操作：

1. 打开你的仓库 <https://github.com/g1289411912-max/->
2. 点 **Add file → Upload files**
3. 把本地 **`德语介宾助手\jiebin` 这个文件夹整个拖进去**（拖文件夹，不是拖里面的单个文件）
   - 拖进去后页面上会显示 `jiebin/index.html`、`jiebin/manifest.json` 等，说明目录被正确保留了
   - 只拖里面 4 个文件的话会散落到根目录，所以**要拖文件夹本身**
4. 拉到底点 **Commit changes**

搞定后你的手机网址就是：

```
https://g1289411912-max.github.io/-/jiebin/
```

> 仓库名是 `-`，所以网址里会出现 `/-/`，这是正常的。
> 等 30–60 秒再打开（GitHub Pages 有部署延迟）。

---

## 三、手机上第一次使用

1. 手机浏览器打开上面的网址
2. 点「**导入条目 (.md)**」→ 选你手机里的 `条目.md`
3. 点「**导入解析 (.md)**」→ 选 `解析.md`（或 `解析（重写）.md`）
4. 提示「导入成功：318 条 / 解析导入成功：496 条」就可以了
5. **加到主屏**：
   - iPhone Safari：底部「分享」→「添加到主屏幕」
   - Android Chrome：右上角菜单 →「添加到主屏幕 / 安装应用」
   - 加完点图标就是全屏 App，**断网也能用**

> 手机上的文件怎么来？把 `条目.md` / `解析.md` 通过微信/QQ 发到手机，用「文件」App 存一下，导入时就能选到。

---

## 四、以后更新内容（核心流程）

条目或解析改了以后：

1. 电脑上把新的 `.md` 发到手机（微信传文件最省事）
2. 手机打开助手 → 点「**导入条目**」重新选一次新文件（解析同理）
3. 覆盖后**进度、错题本、笔记全都保留**（它们按「动词+介词」独立存着）

> 如果新文件只是**加了一些条目**、旧的没删，也可以只导入新的那份——同一条会自动去重。
> 想确认导入对不对：点首页「**词表体检**」，能看到解析出多少条、跳过哪些行、去掉了哪些重复。

## 五、常见问题

**Q：网址打不开 / 404？**
- 确认文件放在 `jiebin/` 文件夹里，且应用文件名是 `index.html`（不是 `德语介宾助手.html`）
- 刚上传完等 30–60 秒（Pages 有部署延迟）

**Q：改了应用本身（不是词表）怎么更新？**
- 把新的 `德语介宾助手.html` 内容重新粘贴/上传覆盖 `jiebin/index.html` → Commit → 手机刷新
- 如果刷新后还是旧版：手机浏览器清一下该站点缓存，或等 1 分钟再刷

**Q：手机上「导入」能选到 .md 吗？**
- 能。Android 的文件选择器、iPhone 的「文件」App 都支持选 `.md`。
- 如果文件选择器只让选某些类型，先确认文件后缀是 `.md` 或 `.txt`。

**Q：为什么不做成「打开就有词表」？**
- 因为你的词表经常更新，内嵌进网页的话每次都得重新构建、重新上传；直接导入 `.md` 更灵活。

**Q：数据会上传吗？**
- 不会。导入的 `.md` 只存在你手机浏览器本地（localStorage），练习进度也一样。仓库里只有代码，没有你的词表内容。

**Q：断网能用吗？**
- 能。第一次打开后 Service Worker 会缓存应用本身；条目/解析/进度本来就在本地。
