# 手机使用部署说明（GitHub Pages）

目标：**电脑上把词表 / 语法笔记上传一次，手机上打开网址就能全部功能使用**，还能加到主屏当 App、断网也能用。

---

## 一、准备

1. 注册一个 GitHub 账号（免费）：<https://github.com/signup>
2. 本文件夹里已经放好了：
   - `index.html` —— 应用本体（已做手机适配 + 同步功能 + 语法通读模式 + PWA）
   - `data/words/` —— **词表**（已放入你的 第一单元 + 课内词条）
   - `data/details/` —— **解析/详解**（已放入 课内解析）
   - `data/grammar/` —— **语法笔记**（已放入 第一单元 + 表达喜欢的词）
   - `更新索引.bat` / `上传到GitHub.bat` / `manifest.json` / `sw.js` / `icon.svg`

---

## 二、创建仓库并上传（选一种方式）

### 方式 A：网页拖拽（最简单，不用装任何东西）

1. 打开 <https://github.com/new>
2. **Repository name** 填 `deutsch`（或任意英文名），选 **Public**（必须公开，Pages 免费版才可用），点 **Create repository**
3. 在空仓库页面点 **uploading an existing file**
4. 把本文件夹里的**所有文件/文件夹**（`index.html`、`data` 文件夹、`manifest.json`、`sw.js`、`icon.svg` 等）一起拖进去
   - ⚠️ 注意：要拖 `data` **文件夹本身**（GitHub 会自动展开上传里面的文件）；不要只拖 .bat/.ps1（那两个是电脑本地用的，上传与否都行）
5. 下方点 **Commit changes**

### 方式 B：一键脚本推送（以后更新更快）

1. 先按上面步骤 1-2 建好空仓库，复制它的地址（形如 `https://github.com/你的用户名/deutsch.git`）
2. 双击本文件夹里的 **`上传到GitHub.bat`**
   - 第一次会提示你输入仓库地址（粘贴进去回车）
   - 如果提示未登录：先在电脑上装 Git 并登录一次（或改用方式 A 的网页拖拽）
3. 之后每次更新，只要双击 `更新索引.bat` → `上传到GitHub.bat` 即可

---

## 三、开启 GitHub Pages（得到手机能访问的网址）

1. 进入你的仓库 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
4. 等 1 分钟左右刷新页面，顶部会出现网址：

   ```
   https://你的用户名.github.io/deutsch/
   ```

   （这就是你的手机网址，建议存到手机浏览器书签）

---

## 四、手机上使用（第一次）

1. 手机连网（WiFi 或流量都行），用浏览器打开上面的网址
2. 点设置区的 **「☁️ 同步数据」** → 会提示「同步完成 ✓ 词表 xxx 词 · 详解 xx 条 · 语法笔记 xx 个」
3. 之后就可以正常练了（词表、进度、笔记都自动存在手机本地）
4. **加到主屏当 App**：
   - iPhone Safari：底部「分享」→「添加到主屏幕」
   - Android Chrome：右上角菜单 →「添加到主屏幕」/「安装应用」
5. 语法笔记查看：点 **「语法检测」→「📖 通读模式」** —— 连续阅读全部笔记（带目录、可搜索）

---

## 五、以后更新词表 / 语法笔记（核心流程）

1. **电脑上**替换或新增文件到对应文件夹：
   - 词表 → `data/words/`（放 .md 文件，支持多个文件自动合并）
   - 详解 → `data/details/`
   - 语法笔记 → `data/grammar/`
2. 双击 **`更新索引.bat`**（自动刷新 `data/index.json`，让应用知道有哪些文件）
3. 上传到 GitHub：
   - 网页方式：进仓库 → 进对应文件夹 → **Add file → Upload files** → 拖入新文件 → Commit
   - 脚本方式：双击 **`上传到GitHub.bat`**
4. 等 30 秒左右，**手机上打开网址点「☁️ 同步数据」** → 新内容就进来了

> 小提示：文件名建议用英文/数字（如 `unit2-vocab.md`）。中文文件名在个别手机上可能取不到。

## 六、常见问题

**Q：点「同步数据」提示失败？**
- 确认是**通过网址**打开（`https://...`），不是双击本地文件
- 确认仓库里有 `data/index.json`（本地先运行一次 `更新索引.bat` 再上传）
- 刚上传完等 30-60 秒再试（GitHub Pages 有部署延迟）

**Q：手机上的数据和电脑上的进度是同一份吗？**
- 不是。同步只负责"把电脑上的词表/笔记搬到手机"，**练习进度、错题本、笔记、任务、计时都存在各自设备的本地**，互不干扰。

**Q：断网能用吗？**
- 能。第一次打开并同步后，Service Worker 会缓存应用和数据，之后断网打开也能用（数据取上次缓存）。

**Q：词表内容会公开吗？**
- 用 Public 仓库的话，`data/` 下的词表/笔记是公开可访问的（网址可猜）。只是个人背单词内容一般无所谓；如介意可把仓库设为 Private（Private 仓库的 Pages 需要付费账号，或者改用本地方案）。

**Q：手机上「导入词表」还能用吗？**
- 能，功能完全一样（手机文件选择器选 .md 即可），和「同步数据」互不冲突。
